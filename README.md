# UTS PAM — Mobile Computing

Project Ujian Tengah Semester (UTS) mata kuliah Pemrograman Aplikasi Mobile menggunakan React Native dan Expo.

## Teknologi
- React Native
- Expo
- Expo Router

## Cara Menjalankan Aplikasi

1. Pastikan Node.js sudah terpasang.
2. Buka terminal pada folder project.
3. Install dependency:

   ```bash
   npm install
   ```

4. Jalankan aplikasi:

   ```bash
   npx expo start
   ```

5. Ikuti instruksi pada terminal untuk membuka aplikasi melalui Expo Go atau browser.

## Pengembangan

Kode aplikasi dan halaman berada di folder `app`. Edit file yang sesuai untuk mengembangkan fitur aplikasi.
